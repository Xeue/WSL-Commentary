3. HOW THESE COMPONENTS ARE USED IN THIS PRODUCT
------------------------------------------------

Every component listed in section 2 is shipped UNMODIFIED, in binary form, as a
separate dynamic-link library (DLL) in the program folder. None of them is
linked statically into wslcomms.exe, and no part of any of them has been
altered.

The application loads these libraries at run time, by name, from the program
folder. A recipient who wishes to use a modified but interface-compatible build
of any of these libraries may replace the corresponding DLL in that folder, and
the application will load and use the replacement. No relinking of wslcomms.exe
is required to do this. This is the "suitable shared library mechanism" of
section 6(b) of the GNU Lesser General Public License version 2.1.

Prominent notice, as required by section 6 of that licence: this product uses
the GStreamer and GLib libraries, and those libraries and their use are covered
by the GNU Lesser General Public License version 2.1, a copy of which is
supplied with this product in the file LGPL-2.1.txt in the same folder as this
document.
